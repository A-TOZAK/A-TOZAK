# ふきだしくん

教育現場向けのリアルタイム意見共有ツールです。授業中に生徒や参加者が自由に意見を投稿し、共有できます。

## 主な機能

### 基本機能
- ✅ **ボード作成**: URLハッシュで共有可能なボードを自動生成
- ✅ **名前入力**: 初回アクセス時に名前を入力(匿名可)
- ✅ **5ページ対応**: 最大5ページのボードでトピックを分類
- ✅ **ふきだし投稿**: 意見を色付きふきだしで投稿
- ✅ **ドラッグ&ドロップ**: ふきだしを自由に移動
- ✅ **リアルタイム共有**: 複数ユーザーで同時編集可能

### 追加機能
- ✅ **いいね機能**: 他の人の意見に共感を表明
- ✅ **編集・削除**: 自分の投稿のみ編集・削除可能
- ✅ **5色背景**: 青、緑、黄、ピンク、オレンジから選択
- ✅ **投稿者名表示**: 誰が投稿したかが分かる

## 技術スタック

- **React 18**: UIフレームワーク
- **Vite**: ビルドツール
- **Tailwind CSS**: スタイリング
- **window.storage API**: リアルタイム同期(ブラウザ標準APIへのフォールバック対応)

## 使い方

### 1. ボードの作成
- 初回アクセス時に自動的にボードIDが生成されます
- 名前を入力して「ボードに入る」をクリック(空欄で匿名)

### 2. URLの共有
- ヘッダーの「URLコピー」ボタンでリンクをコピー
- 生徒や参加者にURLを共有

### 3. ふきだしの投稿
- 右下の「+」ボタンをクリック
- 内容を入力し、背景色を選択
- 「作成」ボタンで投稿

### 4. ふきだしの操作
- **移動**: ふきだしをドラッグ&ドロップ
- **いいね**: ❤️ボタンをクリック
- **編集**: ✏️ボタンで自分の投稿を編集(投稿者のみ)
- **削除**: 🗑️ボタンで自分の投稿を削除(投稿者のみ)

### 5. ページの切り替え
- ヘッダーの「ページ1」〜「ページ5」で切り替え
- 各ページで独立した内容を管理

## データの保存

- ブラウザの`window.storage` API(shared: true)を使用してリアルタイム同期
- APIが利用できない場合は自動的にlocalStorageにフォールバック
- 各ボード・各ページごとにデータを保存

## デプロイ

### GitHub Pagesへのデプロイ

1. `vite.config.js`にbase設定を追加:
```js
export default defineConfig({
  plugins: [react()],
  base: '/fukidashi-kun/',  // リポジトリ名に合わせる
})
```

2. ビルドとデプロイ:
```bash
npm run build
# distフォルダをgh-pagesブランチにデプロイ
```

### その他のホスティング
- Netlify
- Vercel
- Firebase Hosting

静的ファイルとして動作するため、どのホスティングサービスでも利用可能です。

## 教育現場での活用例

- **ブレインストーミング**: アイデアを自由に出し合う
